## 1. 演示时敲这一条

```powershell
.venv/Scripts/python.exe -m net.launcher
```

一条命令做完：装证书 → 起抓包（带看门狗）→ 开面板 → **退出时全部还原**。

## 2. 屏幕上按这个顺序出现

| 位置 | 内容 |
|---|---|
| 顶部 | 级别「打X」、现在轮到谁 |
| 左下 | **我的手牌**（按掼蛋大小排好了） |
| 中间 | 台面（谁出的、什么牌型） |
| 右侧 | **模型建议**：首选大图 + 两个备选小图（**不写分数** —— 你定的） |
| 底部 | 记牌：每家出过什么、还剩几张 |

## 3. 出问题时的备选（按可能性排序）

| 症状 | 敲什么 |
|---|---|
| 级别显示不对／空白（**最可能**：游戏日志被轮转了） | `--level 8`（打几输几） |
| 建议栏空着 | 先确认是不是「还没轮到我」（不是轮到你时它本来就空）；真有问题 → `--console` 换终端版 |
| 不想让建议上屏（比如要证明「人自己打」） | `--no-show-advice`（算但不说，记录里如实写 `advice_shown:false`） |
| 只想检查环境、不动代理 | `--dry-run` |

## 4. 客户会问的数字 —— **三把一起报**

| 打谁 | 战绩 |
|---|---|
| 随机 | 98.2% |
| 贪心（能压就压的机器人） | 95.2% |
| **像人的规则 AI** | **54.8%** |
| 你真机打时，跟它建议一致的比例 | 90% |

⚠️ **别只报 95.2%** —— 那把尺子早打穿了（它只是个「会压牌」的机器人）。
**54.8% 才是真实水平**：略强于一个手写规则策略。这么说反而是加分项 ——
说明我们的**尺子比同行严格**，而且现在有 45 个百分点的空间可以量出进步。
