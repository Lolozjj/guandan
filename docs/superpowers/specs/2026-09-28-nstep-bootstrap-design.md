## 1. 目标与成功判据

**要治的病**：模型给的推荐牌不够好（用户 2026-09-26 报的「有普通牌能压却出炸」是其中一例）。
已经试过三条路，全部没治：混入固定对手、对手池（league+PFSP）、动作计价（炸弹代价）。

**根因（2026-09-28 收敛）**：**一局 ~132 个决策点共享同一个标签。**

```
y_t = R          ← 终局 ±分，整局所有决策点相同
```

标签**不依赖第 t 步选了哪个动作**（只通过已实现的轨迹间接依赖）。后果：

- 网络只好去学「从这个局面能拿几分」——那是个**状态值**；动作那一维只剩残差。
- 实测：候选间离散度中位 **0.401**、首选次选之差中位 **0.123**，而标签尺度 **±3**。
- 路线①（给炸弹挂动作代价）**验证了机制**：给一个动作挂上代价，它的浪费就降了
  （9 个检查点里 8 个方向一致，合并 4.86% → 4.45%，守门人全过）——
  **但只覆盖炸弹那一个动作**，其余 ~130 个决策点照旧共享一个标签。

**目标**：让目标的**每一个**决策点都看**它自己把局面带到了哪里**，而不是整局的结局。

### 成功判据（按顺序，预登记，不许事后改）

1. **`vs 贪心` 不许掉 ≥1 个标准差** —— 判据，也是「有没有学歪」的守门人。
2. **动作边际（首选次选之差的中位）要变宽** —— **机制层面的直接证据**。
   现在是 0.123。自举如果起作用，Q 对动作的区分度就该变大。
   ⚠️ **它必须和第 1 条一起看**：边际变宽而 `vs 贪心` 掉 ⇒ 那是数值发散，不是变好。
3. **`bomb_waste` 两个数（自对弈 / 面对贪心）都要降** + **用炸率不许塌**。
   这一条是**次要**的：路线②治的不是炸弹，但如果连炸弹都没好，说明没起作用。
4. **真机影子日志同向** —— 唯一来自真实对局的证据（要用户打牌）。
5. **杀停**：第 1 条或第 2 条不满足 ⇒ **停路线②**。到那时该回头质疑
   「值函数 + argmax」这个框架本身（不是再换个目标）。

## 2. 已确认的事实（都带证据，别重新推导）

- **标签不依赖动作**：见 §1 的公式与实测（离散度 0.401 / 边际 0.123 / 尺度 ±3）。
- **三条路都试过、都没治**：
  - 混入固定对手（0940）：`bomb_waste` 面对贪心 5.1%，无改善
  - 对手池（R2 复跑，按设计剂量、两臂串行）：同局数 2 万…24 万配对平均差 −0.13 个百分点；
    炸弹浪费 5.2% vs 4.9%（0.4 sd）；**每小时还少跑 39% 的局**
  - 动作计价（2026-09-28）：方向对、**0.4 个百分点**，实际用不出来
- **池子那一轮的反证**：池子臂里学习者对池成员的胜率是 **38~58%**（真五五开、
  标签有对比）**照样没进步** ⇒ 「对手不够强」被排除。
- **ε 与热启动已经修好**：热启动时 ε 起点压到 0.3（`EPS_START_WARM`）。
  修完之后两臂 40 万局**都守住** `vs 贪心` 95.0~95.5%（起点 95.2%）——
  而没修之前 24 万局就掉到 92.8~94.2%。**所以「从强存档出发就退」已经不再是干扰项。**
- **重放能拿到每一步的 `(obs, acts)`**：`replay.expand` 本来就逐步走完整局
  （为了推进局面），所以 `s_{t+n}` 与它当时的候选**都是现成的** —— 这是本方案
  在工程上可行的关键，不需要新机制。
- **`replay.py` 刻意不 import torch**（见它的 docstring）。所以自举那一项
  **不能**写在 replay 里 —— 它要去 `train/selfplay.py`（有 torch 那边）算。
- **学习进程是瓶颈**（spec §14.3）：自举要多算一遍「后继局面的 V」，
  **训练步的前向大约翻倍**。这是本方案的主要成本，见 §6。

## 3. 架构

### 3.1 标签怎么变

```
现在：  y_t = R                                    （整局一个值）
改成：  y_t = (1 − β) · V̄(s_{t+n})  +  β · R
        β = 1 → 完全就是现在的 DMC（**默认值**）
        β = 0 → 纯 n 步自举
        若 t+n 越过终局：整项退回 R（不 bootstrap）
```

- **`V̄(s) = max_a Q̄(s, a)`**，`Q̄` 是**目标网络**（`net` 的冻结副本，定期同步）。
- **`n` 是自举的步数**（初值 3）。`n` 越大越接近 MC（偏差小、方差大），
  `n=1` 最偏但最稳 —— 这是偏差-方差的那把旋钮。
- **γ = 1（不打折）**：一手牌是有限回合、没有时间价值，而当前标签尺度就是 ±3；
  打折会改变量纲、让「早期决策」的目标变小（那是另一件事，不在本轮）。

**为什么是这个形状（而不是纯 TD）**：纯 TD（`β=0`）+ 无逐步回报时
`y_t = V̄(s_{t+n})` —— 而网络没训好时 `V̄ ≈ 0`，目标就成了「网络自己现在的预测」，
**会塌成一个常数**（自我实现的定点，终局那个锚点传播得太慢）。
把 `R` 按 `β` 混进来，**塌不了**，而且给了一把从「稳但平」（β=1）到
「有动作对比」（β→0）的连续旋钮。

### 3.2 数据流（谁算什么）

```
replay.expand(rec, n=0)
    → (points, y_mc, boot)          ← y_mc = mc_targets(...)；boot[i] = s_{t+n} 的 (obs, acts)
train/selfplay.py 的训练步
    → y = (1−β)·qmax(Q̄, boot) + β·y_mc        ← 唯一算自举项的地方（有 torch）
    → MSE(y_hat, y)
```

- `n=0` 时 `boot` 是空表，`y` 就等于 `y_mc` ✓ **行为不变**。

⚠️ **`expand` 的返回要从 2 元组变成 3 元组**（`(points, y, boot)`），
所以**调用方都要跟着改**：`replay.play_capturing`、`train/selfplay.py` 的训练步、
以及 `tests/` 里所有 `pts, y = replay.expand(...)` 的地方。
这是**明说的改动面**（不是「一行不变」）—— 行为不变由测试 4 钉住。
不想动这么多地方的话，另一个选择是 `want_boot=False` 时仍返回 2 元组，
**但那样返回元数就随参数变**，是个更难查的坑；不采用。
- **`y_mc` 仍然只由 `mc_targets` 产出**（那条纪律不变）；自举项只加在**一处**。
- **worker 完全不动**：自举只发生在学习者那一侧 ✓（多进程那条路不用改）

### 3.3 目标网络

- 学习者持有 `net_tgt`，**每 `TGT_SYNC_GAMES`（初值 1000，与权重广播同拍）**
  从 `net` 复制一次。
- `net_tgt` 只用于算目标，**永远不参与优化**（`requires_grad=False`）。
- **`qmax(Q̄, boot)` 用 `torch.no_grad()`** —— 忘了它就是「对目标求导」，静默地学歪。
- **`train/net.py` 要新增 `q_max_batch(net, pending) -> list[float]`**：
  现有 `q_argmax_batch` 返回的是**下标**，这里要的是**最大值**。
  批处理的形状照抄它（候选不等长就不 padding，首尾相接按下标区间取 max）。

### 3.4 两条纪律

1. **`β=1` 时必须与现在逐点相等** —— 有测试钉着（同种子、同一批记录）。
2. **四次前向要分开算**：`Q(s,a)` 与 `Q̄(s_{t+n}, ·)` 是两次前向，
   别拼在一起（拼了会把目标也卷进梯度图）。

## 4. 关键取舍

| 取舍 | 选择 | 为什么 |
|---|---|---|
| 要不要自举 | **要** | 它是**唯一**让目标依赖「动作带来的后继局面」的机制。MC 的逐步奖励会望远镜化成状态基线（路线① spec §1 的算术），路线①的实测也印证了「一个动作挂着代价，只有一个动作变好」 |
| 纯 TD 还是 TD/MC 混合 | **混合（`β` 旋钮）** | 纯 TD 在 `V̄≈0` 时会塌成常数；混合有 `R` 兜底，且 `β=1` 就是老行为 |
| 折扣 γ | **1（不打折）** | 有限回合、无时间价值；保持标签量纲与现状一致 |
| 目标网络 | **要** | 没有它，自举就是「追自己的尾巴」，发散风险大增。代价是 7.8 MB 显存 + 一次复制 |
| 用不用重要性采样 | **不用** | 缓冲区里是 ε-greedy 的行为策略，n 小的时候偏差有限；这是**已知的取舍**，写在这里而不是假装没有 |
| 盖不盖掉路线① | **不盖** | 炸弹代价仍在（`--bomb-cost`，默认 0）。本轮 A/B **两臂都 λ=0**，只差 β 一个变量 |

## 5. 验收

### 5.1 A/B（主判据）

两臂都从**同一个存档**热启动（`runs/rl/20260926-1407/best.pt`）、同种子、
同秒数、`--bomb-cost 0`、`--pfsp` 关、**串行跑**（并发会内存打死，吃过一次）：

- **对照臂**：`--mc-mix 1.0`（= 现在的 DMC）
- **处理臂**：`--mc-mix 0.5`（一半自举、一半 MC）—— 先别一步跳到 `β=0`

⚠️ **同秒数 ≈ 同局数**（两臂都不开池子，速率应当相同）；仍用 `--snap-every`
的快照做同局数配对。

### 5.2 同一把尺子

`tools/ab_compare.py`（已有 `vs 贪心` / `bomb_waste` / **用炸率**），
外加**动作边际**：

- `vs 贪心`（400 局 `seed=1002`）、`vs 随机`
- `bomb_waste` 两个数 + `bomb_rate`（防塌）
- **动作边际**：对一批真实决策点算 `top1 − top2` 的**中位**（现在 0.123）。
  做法：自对弈打几十局、抓决策点，对每个局面的**每个候选**跑 `q_values`
  取排序后的前两名之差。⚠️ **这次要落成 `tools/` 里的脚本** ——
  9-27 那次是在临时目录里做的，清理完数字就不可复现了（评审的 M8 提过同一件事）

### 5.3 单元测试

1. `β=1` 时标签与现在**逐点相等**（默认行为不变）
2. `β<1` 且 `n` 越界时整项退回 `R`
3. 目标项**不带梯度**（`requires_grad=False`；对 `net_tgt` 求导会报错）
4. `expand(n=0)` 的返回与现在逐点相等（`boot` 为空）
5. `qmax(Q̄, boot)` 在两个人造网络下给出**不同**的值（防「拿错了网络」）

### 5.4 真机（唯一来自真实对局的证据）

训练完请用户打几局，读 `net/shadow.jsonl`（按 `session` 切分、去重、
用 `legal_moves` 真枚举候选）。**用户最初的抱怨从这儿来，也只有这儿能结案。**

### 5.5 成本要先量

自举让训练步的前向大约翻倍，而**学习进程就是瓶颈** ⇒ 局/秒会掉。
**先把这一项量出来再决定预算**（参照 `tools/bench_train.py` 的做法，
每档跑足 3 分钟 —— 短跑会把进程启动成本摊进去，这个坑踩过）。

## 6. 风险与应对

| 风险 | 应对 |
|---|---|
| **发散**（off-policy + 自举 + 函数逼近 = 致命三角，DouZero 正是为此选了纯 MC） | 目标网络 + `β` 从 0.5 起而不是 0；判据 1 就是守门人。**再加法子**：训练中监控 `|Q|` 的量级与 loss，超阈值**响亮地炸**（本仓库纪律：失败必须响），不静默地训下去。
  **具体阈值**：一个 batch 里 `|Q|` 的最大值 > **30**（标签尺度是 ±3，
  一个数量级以上的偏离只可能是发散）就 `raise`，并打出当时的 loss 与 games |
| **塌成常数**（纯 TD 且 `V̄≈0`） | `β` 混合里有 `R` 兜底；测试 1 钉住 `β=1` |
| 目标项被卷进梯度图 | 测试 3；实现里 `no_grad` |
| **成本被低估** | §5.5：先量前向翻倍的真实代价，再定预算 |
| 边际变宽但其实是数值发散 | 判据 2 **必须**和判据 1 一起看（§1.2 的警告） |
| 重要性采样缺失带来的偏差 | 明确写在 §4 的取舍里；`n` 小 ⇒ 偏差有限。**不假装没有** |
| 真机证据拿不到 | 只认离线判据，并在结论里写明「没有真机证据」 |

## 7. 不在范围内

- 换回路线①（炸弹代价调大）—— 它只治炸弹，按 §1 的算术治不了这个病
- 动对手（池子已证否）、动网络结构、动状态/动作编码、动判据阈值
- actor-critic / PPO
- MCTS / rollout
- 真机自动打牌（项目红线）
- **同时**改炸弹代价与自举（两件事一起改，出了效果分不清是谁的功劳 —— 刚吃过这个亏）

## 8. 需要定的初值

| 常量 | 初值 | 依据 |
|---|---|---|
| `N_STEP`（n） | **3** | 一局每座位约 33 个决策点；n=1 最偏、n=∞ 就是 MC。3 是中间偏保守 |
| `MC_MIX`（β） | **0.5** | 先别一步跳到纯自举；对照臂用 1.0 |
| `TGT_SYNC_GAMES` | **1000** | 与权重广播同拍（那个节奏已经验过不会拖死 learner） |
| `GAMMA` | **1.0** | 有限回合、无时间价值 |
| A/B 时长 | 各 9000 秒 | 与 R3 那轮可比（那轮 380~397k 局）；**但要先按 §5.5 量成本再定** |
| 杀停阈值 | 1 个标准差 | 预登记，不许事后改 |
