## 1. 为什么是这一条（理由必须写清，否则又是一次「换对手」）

「换对手」在这个项目里**已经被否过两次**（对手池 league+PFSP；n 步自举那轮的动机也是它）。
所以这次必须先回答「**为什么这次不一样**」：

| 当时的否定理由 | 现在的状态 |
|---|---|
| 对手是**贪心**，而贪心早被打穿（95% 胜率）⇒ 「一半算力花在一个已经打穿的对手身上」 | 换 `rule` —— 而 **`rule` 今天之前也是个被打穿的对手**（1407 打它 88:12），所以这个理由当时**对 `rule` 同样成立** |
| 「对手太弱 ⇒ 学不到东西」 | ⚠️ **那条依据是坏的**：88:12 是**尺子自己的 bug** 造成的（规则式在拆自己的炸）。修完之后是 **55:45** —— **真正的对手** |

⇒ **这是「换对手」这条路上第一次拿到一个真正五五开的对手**。理由是新出现的，不是重复。

## 5. 结果

### 5.1 中途读数（14 万局 / 约 40% 进度，**还没跑完**）

⚠️ **先纠正我第一次读错的地方**：我先量的是 `best.pt` —— 而 `best.pt` 是**按 `vs 贪心` 挑的**，
它从 13:52（1 万局）就没再刷新过。拿它去量等于量了一个**比当前落后 12 倍的检查点**，
所以第一眼看到「两边都掉了」。**要看进度得看 `pool/snap_*.pt`（每 2 万局一份）。**

【主判据】规则式打它们（同种子配对 1002/1004/2000，各 400 局）：

| 快照 | 规则式打它 | 配对差 vs 1407 | |
|---|---|---|---|
| 1407（起点） | 49.3% | 基准 | |
| 40,000 | 45.3% | **−4.00%** | ✓ |
| 80,000 | 45.2% | **−4.08%** | ✓ |
| 120,000 | **41.4%** | **−7.92%** | ✓ |

⇒ **主判据在过，而且是单调变好**（尺子打它越来越吃力）。

【护栏 2】打贪心：1407 **94.1%** → R7@120k **92.7%**，配对差 **−1.42%** ⚠️ 轻微掉了
（我预登记写的是「不许掉」—— **如实记：它掉了**，幅度约为主判据收益的 1/5）。

【参考】白炸 4.2% → 5.7%、用炸率 2.63 → 2.75 手/局（对贪心，60 局——**样本小、噪声约 ±2pp**）。
用炸率没塌 ✓；白炸略差，值得继续盯（那是用户最初的抱怨）。

⚠️ 训练日志里那串 `vs 贪心 86.5%~96.0%` 是**每次只跑 200 局**的评测，抖动很大；
**别拿它当结论** —— 上面那张配对表才是判据口径。

### 5.2 最终结论（跑满 10820 秒 / **509,824 局**，退出码 0）

判据口径：**同种子配对 × 4**（1002/1003/1004/2000），各 400 局。
权重用 `runs/ab/R7_rule/last.pt`（510 万…**50.98 万局**那份）。

| # | 判据 | 结果 | |
|---|---|---|---|
| **1** | `vs 规则式` 比 1407 好 ≥1 sd | **规则式打 1407 = 50.6%、打 R7 = 39.6%** ⇒ 配对差 **−10.94pp**，sd 2.82pp，**t ≈ −7.8**，**4/4 个种子** | ✅ **过了（约 3.9 sd，远超门槛）** |
| 2 | `vs 贪心` 不许掉 | 93.8% → **91.0%**，配对差 **−2.81pp** | ⚠️ **掉了，如实记** |
| 3 | 白炸 ≈ 0 / 用炸率 1~3 | 白炸 4.2% → **6.3%**、用炸 2.63 → **3.03 手/局** | ⚠️ 白炸略差（60 局、噪声 ±2pp）；用炸率仍在带内 |

逐种子：`-8.5 / -13.2 / -8.5 / -13.5`（全部同向）

**结论：「换对手」这条路第一次成立。** 但它不是白来的 —— 主判据赚了 10.9pp，
次判据（打贪心）赔了 2.8pp。方向说得通：训练对手从「能压就压的机器人」换成
「像人的规则式」，它自然更会打前者那类对手、少一点欺负后者。
**这不是「全面提升」，是「换了一个擅长方向」** —— 引数字时别只报一边。

⚠️ **实操要点（部署时会踩）**：`best.pt` 是**按 `vs 贪心` 挑的**，它停在 **12 万局**那版
（14:33 之后 40 万局都没能超过它）。而真正强的是 `last.pt`（50.98 万局）。
⇒ **要部署这份权重，用 `last.pt`（或最新快照），别用 `best.pt`。**
根因是老问题：`vs 贪心` 早饱和、没区分度，拿它当选择标准会挑错模型。
