# 换目标（动作计价 / 炸弹代价）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 DMC 的标签挂一个**挂在动作上**的炸弹代价（`y_t = R − λ·B_t`），造出「炸 vs 不炸」的动作间对比。

**Architecture:** 标签的算法只有**一个**实现（`replay.mc_targets`），现场抓取与 buffer 重放两条路都调它。代价由 λ（`--bomb-cost`，默认 0 = 老行为）控制，只作用于**学习那一队**的决策点。另加一个「用炸率」指标守住「矫枉过正」。

**Tech Stack:** Python、torch、pytest。

**Spec:** `docs/superpowers/specs/2026-09-27-bomb-cost-shaping-design.md`（**先读它**）

## Global Constraints

- **默认行为不变**：`--bomb-cost` 默认 `0.0`，且 `λ=0` 时**生成的局与改动前逐局相等**（同种子）。
- **标签只有一个产地**：`replay.mc_targets`。现场与重放**都**改成调它，并留逐点相等的测试。
- **代价只作用于学习那一队**：先按 `learn` 过滤，再计价（顺序写死）。
- **失败必须响**：λ 为负、`learn` 与 `seq` 对不上、标签条数与决策点数不等 —— 都要报出来。
- **判据与预登记杀停不许改**：`bomb_waste` 降 1sd、`vs 贪心` 不掉 1sd、用炸率不塌。
- 注释里出现的实测数字必须带日期与口径。

## Review Focus（规格没写、但最容易被这几件事咬到）

1. **`B_t` 是「未来」的计数** —— 第 t 步的标签要含**第 t 步自己**的炸弹，也要含它之后同座位用掉的。写成「只数第 t 步」或「只数之后」都能跑，但那是另一个代价。
2. **只数该座位自己的** —— 记成「该队的」或「全场的」都会让标签变味（奖励是出牌人视角的零和量）。
3. **两条路的标签必须逐点相等** —— 现场从 `acts[i]` 拿 Meld，重放从重枚举的 `acts` 拿；两边候选枚举口径一致（都是 `env.legal()`），但顺序与过滤必须对齐。
4. **`λ=0` 必须真的等价于改动前** —— 不是「差不多」：同种子下生成的局要逐局相等。
5. **别把 `bomb_waste` 的语义改了** —— 它返回 `(浪费数, 能出普通牌的机会数)`，全项目在用。加「用炸率」要**新函数**，共用内部走局但不动签名。
6. **ε 与热启动**：本轮两臂都热启动，ε 起点自动是 0.3（2026-09-27 修）—— 不要以为还是 1.0。

```python
"""动作计价（炸弹代价）—— 标签的唯一实现。

规格：`docs/superpowers/specs/2026-09-27-bomb-cost-shaping-design.md`。

**为什么这条路**：一局 ~132 个决策点共享同一个终局标签 ⇒ 动作那一维只剩残差
（实测首选次选之差中位 0.123，标签尺度 ±3）。把代价**挂在动作上**才能造出
「炸 vs 不炸」的对比 —— 挂在状态上的（势函数）在 MC 里会塌成状态基线。
"""
import pytest

from net.sim import meld
from train import replay

#: 真炸弹：5♠5♥5♣5♦（同副四张同点）。`is_bomb` 为 True。
#: ⚠️ **同花顺也算 `is_bomb=True`**（掼蛋里它本来就是炸），所以代价会一并计上它。
BOMB = [21, 37, 53, 69]
PLAIN = [21, 37]                    # 5♠5♥，一对，`is_bomb` 为 False


def _m(card_ids, level=2):
    m = meld.as_meld(list(card_ids), level)
    assert m is not None, card_ids
    return m


def test_lambda_zero_reproduces_the_old_label():
    """λ=0 必须**逐点等于**老标签（`rules.reward`）—— 默认行为不变。"""
    from net.sim import rules
    seq = [(0, _m(BOMB)), (1, _m(PLAIN)), (0, None), (2, _m(BOMB))]
    ranks = [1, 2, 3, 4]
    got = replay.mc_targets(seq, ranks, bomb_cost=0.0)
    assert got == [rules.reward(ranks, s) for s, _m_ in seq]


def test_a_bomb_lowers_the_label_by_exactly_lambda_times_its_suffix_count():
    """出炸那一步，比**同座位、同结果**但不出炸的那一步低正好 λ × 从它起的炸数。"""
    ranks = [1, 2, 3, 4]            # 座位 0 第 1 名 -> reward = +?（看 points）
    with_bomb = replay.mc_targets([(0, _m(BOMB))], ranks, bomb_cost=0.2)
    without = replay.mc_targets([(0, _m(PLAIN))], ranks, bomb_cost=0.2)
    assert without[0] - with_bomb[0] == pytest.approx(0.2)
    # 同一局里**之前**的决策点也要被它影响（B_t 是从 t 往后数）
    both = replay.mc_targets([(0, _m(PLAIN)), (0, _m(BOMB))], ranks, bomb_cost=0.2)
    alone = replay.mc_targets([(0, _m(PLAIN))], ranks, bomb_cost=0.2)
    assert alone[0] - both[0] == pytest.approx(0.2), "第 1 步没把后面那手炸算进去"


def test_the_cost_only_counts_the_acting_seats_own_bombs():
    """`B_t` 只数**该座位自己**的 —— 别的座位出炸不该动它的标签。"""
    ranks = [1, 2, 3, 4]
    mine = replay.mc_targets([(0, _m(PLAIN)), (1, _m(BOMB))], ranks, bomb_cost=0.2)
    alone = replay.mc_targets([(0, _m(PLAIN))], ranks, bomb_cost=0.2)
    assert mine[0] == pytest.approx(alone[0]), "把对手的炸算到自己头上了"


def test_learn_filters_inside_the_function():
    """过滤在函数里面做（别让调用方各写一份）—— 只保留 `learn` 里的座位。"""
    seq = [(0, _m(PLAIN)), (1, _m(PLAIN)), (2, _m(PLAIN)), (3, _m(PLAIN))]
    assert len(replay.mc_targets(seq, [1, 2, 3, 4], learn=(0, 2))) == 2
    assert len(replay.mc_targets(seq, [1, 2, 3, 4])) == 4


def test_a_negative_cost_is_rejected():
    with pytest.raises(ValueError):
        replay.mc_targets([(0, _m(PLAIN))], [1, 2, 3, 4], bomb_cost=-0.1)
```

```python
def mc_targets(seq, ranks, learn=None, bomb_cost: float = 0.0) -> list:
    """被保留的那些决策点的 DMC 标签 —— **现场与重放共用的唯一实现**。

    `y_t = R − λ · B_t`，`B_t` = **从第 t 步起、该步座位自己**用掉的炸弹数
    （含第 t 步本身 —— reward-to-go 的口径：逐步代价 `−λ·[a 是炸弹]` 求和）。

    `seq` 必须是**一局全部步骤**：`B_t` 要沿着一局往后数，少一步就数错。
    过滤（`learn`）**在函数里面做** —— 让两个调用方各写一份过滤就是「副本会漂」的入口。
    """
    if bomb_cost < 0:
        raise ValueError(f"bomb_cost 不能为负：{bomb_cost}")
    keep = set(learn) if learn else None
    tail, suffix = {}, [0] * len(seq)
    for i in range(len(seq) - 1, -1, -1):        # 倒着扫，一次算出所有后缀计数
        seat, m = seq[i]
        tail[seat] = tail.get(seat, 0) + (1 if (m is not None and m.is_bomb) else 0)
        suffix[i] = tail[seat]
    return [rules.reward(ranks, seat) - bomb_cost * suffix[i]
            for i, (seat, _m) in enumerate(seq)
            if keep is None or seat in keep]
```

3. `B_t` **只数该座位自己的**（夹一个「对手座位出炸」的局面，该座位的标签不受影响）
