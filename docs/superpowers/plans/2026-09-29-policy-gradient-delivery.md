## 3. 事故：logits 守门**误杀**（2026-09-29，第 8,256 局）

```
RuntimeError: logits 的量级炸了：31.13 > 30（第 8,256 局，loss=0.152）
```

**这是我的设计错误，不是发散。** 现场是健康的：`loss=0.152`、**熵 0.84（没塌）**、
一路 24 局/秒 ✓ ⇒ **误杀**。

**根因**：我把 `Q_ABS_MAX = 30` 照搬到了 logits 上 —— 两者**不同量纲**：

| | 是什么 | 尺度 | 30 意味着 |
|---|---|---|---|
| `Q` | **值** | 标签 ±3 | 发散 ✓（那个守门是对的） |
| **logits** | **对数几率** | **没有有界尺度** | 只是「这一手很确定」，**不是发散** ✗ |

`softmax` 把任何有限 logits 映射成合法分布 ⇒ 几十的 logits 完全正常。

**修法**（`train/net.py`）：
- 新增 `LOGIT_ABS_MAX = 1e4` + `check_logits(zmax, games, loss)` ——
  **纯溢出兜底**（用 `not (x <= limit)` 写，NaN/inf 一起拦住 ✓）
- `_pg_step` 改用它（**不再用 `check_q_scale`**）
- 真正管「策略退化」的是 **`check_entropy`** ✓（那一轮它没响是对的 ✓）
- **回归测试**：`check_logits(31.13, ...)` 不许炸（就是那次误杀的那个值）✓

**代价**：31 分钟 + 一次重跑（相对 2.5 小时不算大 ✗）。**如实记。**

## 5. 结论：纯 REINFORCE **在这套环境/超参下会塌** —— 不给 A/B 结论

### 5.1 证据：熵系数是个**弱**杠杆

| 4 分钟时的熵 | β=0.01 | β=0.03 | β=0.1 |
|---|---|---|---|
| H | 0.668 | 0.670 | **0.774** |

- 0.01 与 0.03 **完全一样**（0.668 vs 0.670）⇒ 小幅提高**没有任何作用**
- 0.1 明显更好（0.774）⇒ **它确实是个杠杆，但太弱**：`0.851 → 0.774` 仍在下滑，
  按这个斜率约 **40 分钟**撞地板 ✗ —— 而 A/B 要 9000 秒（150 分钟）✗
- ⇒ **软性的熵奖励挡不住这个任务的磨尖压力**：梯度 `−Cov(e_a−π, adv)` 的均值
  系统性把概率推向「与赢相关」的动作 ⇒ 趋向确定性是**学习本身**，不是 bug ✓
  而熵项只是设了一个**很尖的**平衡点 ✗

### 5.2 根因（一句话）

**信任域缺失**：纯 REINFORCE 每步可以任意移动策略 ✗ ——
`∇log π(a)·adv` 没有任何东西限制「这一步改了多少」，而熵奖励只是一个软约束 ✓
**标准解法就是 PPO 的 clip（或 KL 约束）** —— 而它被我在 **spec §9 明确划到范围外** ✗✗

⇒ 这不是实现 bug，是**范围选择的后果**：我把「先做最简单的策略式」定成了 v1，
而最简单的那一版在**这个任务上不稳** ✓ 这条本身就是有价值的结论 ✓

### 5.3 状态（**给下一个会话**）

- **代码是完整且测过的**：`--algo pg` 全通、**509 passed / 2 failed**（两条环境红）、
  三个真 bug 都修了并有回归测试 ✓
- **但 `--algo pg` 现在不能拿来跑长训练** ✗：会在 ~30~60 分钟内熵塌，被守门炸掉 ✓
  （守门是**对的** —— 塌了就没有探索、梯度也退化了 ✓）
- **不要**把「调 β_ent」当成下一步就完事 ✗（实测 0.01/0.03 无差别、0.1 只延后）
- **下一步的三个候选**（按代价）：
  1. **PPO 的 clip**（信任域）—— 与 spec §9 划掉的那条正是同一条 ⇒ 现在有实测理由把它**拿回来** ✓
     实现便宜：数据是「一步之前」的 ✓ 用 `lp` 在更新前 detach 当参考即可；
     但要**多轮更新同一个 batch** clip 才会生效 ✓
  2. **给策略自己的尺度**（温度 / 独立的输出头、小初始化）——
     Q 的尺度是「回归几分」这个任务定的，和策略需要的尖锐程度无关 ✓ 这是**设计层面**的修
  3. **硬性探索下限**（ε-greedy 保留）—— 能保住**数据**的多样性 ✓
     但注意：`∇log π(a)·adv` 会把随机采到的那 10% 压下去 ⇒ **策略照样会塌** ✗
     （所以它单独不够 ✓）
